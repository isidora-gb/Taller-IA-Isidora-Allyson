# Análisis de Datos de un Sistema de Generación Eólica

## Descripción del proyecto

Este repositorio contiene el desarrollo de un proyecto académico orientado al procesamiento y análisis de datos registrados por sensores de un sistema de generación eólica, con el propósito de caracterizar su comportamiento e identificar posibles anomalías en las mediciones.

## Metodología

El estudio comprende la exploración y limpieza de datos, el análisis estadístico de las variables del acelerómetro, giroscopio, magnetómetro y sensor de temperatura, así como la identificación y tratamiento de valores atípicos mediante el criterio de 6σ.

Adicionalmente, se aplican técnicas de análisis de correlación y análisis de componentes principales (PCA) para estudiar las relaciones entre variables y explorar patrones multivariables.

## Herramientas utilizadas

Python, Pandas, NumPy, Matplotlib y Scikit-learn.

## Fuente de datos

[Base de datos del sistema de generación eólica — Kaggle](https://www.kaggle.com/datasets/railwayuaq/base-de-datos-del-sistema-de-generacin-elica)
